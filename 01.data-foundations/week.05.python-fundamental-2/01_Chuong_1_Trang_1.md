## 1. GIỚI THIỆU VỀ PYTHON

### ★ Python là gì?

Python là một **ngôn ngữ lập trình bậc cao, thông dịch, đa mục đích** (general-purpose). Nó được tạo ra bởi **Guido van Rossum**, và phát hành vào năm **1991**. Python được thiết kế để **dễ đọc** và **đơn giản khi sử dụng**.

**Đặc điểm nổi bật**

- Dễ học và dễ sử dụng
- Cú pháp rõ ràng, dễ đọc
- Ngôn ngữ thông dịch (Interpreted)
- Ngôn ngữ bậc cao (High-level)
- Độc lập nền tảng (Platform Independent)
- Hướng đối tượng (Object-Oriented)
- Thư viện chuẩn phong phú
- Mã nguồn mở (Open Source)

### ★ Tại sao chọn Python?

- Đơn giản và dễ học.
- Phạm vi ứng dụng rộng.
- Cộng đồng hỗ trợ lớn.
- Tương thích đa nền tảng (cross-platform).
- Thường xuyên được cập nhật và cải tiến.

### ★ Ứng dụng của Python

- Phát triển Web (Django, Flask)
- Data Science & Machine Learning
- Artificial Intelligence
- Automation / Scripting
- Phát triển Game
- Ứng dụng GUI Desktop
- Cyber Security, Networking và nhiều lĩnh vực khác..

### ★ Chương trình Python đầu tiên

```python
# Đây là chương trình Python đơn giản
print("Hello, World!")
```

**Output:**

```text
Hello, World!
```

> Mọi chương trình Python đều bắt đầu với thụt lề (indentation) và cú pháp đơn giản.

### ★ Python hoạt động như thế nào?

```text
Viết code trong file Python (.py)
    → Python Interpreter đọc code
    → Interpreter chuyển đổi thành bytecode
    → Python Virtual Machine (PVM) thực thi
    → Kết quả được hiển thị trên màn hình
```

### ★ Comment trong Python

```python
# Đây là comment một dòng
# Comment dùng để giải thích code
```

> Comment sẽ bị bỏ qua bởi interpreter.
