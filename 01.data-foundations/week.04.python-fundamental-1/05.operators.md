# Toán tử

Toán tử là những ký hiệu đặc biệt dùng để thực hiện các phép tính trên giá trị và biến.

## 1. Toán tử số học

| Toán tử | Tên gọi | Ví dụ | Kết quả |
| --- | --- | --- | --- |
| `+` | Cộng | `5 + 3` | `8` |
| `-` | Trừ | `5 - 3` | `2` |
| `*` | Nhân | `5 * 3` | `15` |
| `/` | Chia | `5 / 3` | `1.666...` |
| `//` | Chia lấy phần nguyên | `5 // 3` | `1` |
| `%` | Chia lấy dư | `5 % 3` | `2` |
| `**` | Lũy thừa | `5 ** 3` | `125` |

## 2. Toán tử so sánh

| Toán tử | Tên gọi | Ví dụ | Kết quả |
| --- | --- | --- | --- |
| `==` | Bằng | `5 == 5` | `True` |
| `!=` | Khác | `5 != 3` | `True` |
| `>` | Lớn hơn | `5 > 3` | `True` |
| `<` | Nhỏ hơn | `5 < 3` | `False` |
| `>=` | Lớn hơn hoặc bằng | `5 >= 3` | `True` |
| `<=` | Nhỏ hơn hoặc bằng | `5 <= 3` | `False` |

## 3. Toán tử gán

| Toán tử | Ví dụ | Tương đương với |
| --- | --- | --- |
| `=` | `x = 5` | `x = 5` |
| `+=` | `x += 2` | `x = x + 2` |
| `-=` | `x -= 2` | `x = x - 2` |
| `*=` | `x *= 2` | `x = x * 2` |
| `/=` | `x /= 2` | `x = x / 2` |
| `%=` | `x %= 2` | `x = x % 2` |
| `**=` | `x **= 2` | `x = x ** 2` |
| `//=` | `x //= 2` | `x = x // 2` |

## 4. Toán tử logic

| Toán tử | Tên gọi | Ví dụ | Kết quả |
| --- | --- | --- | --- |
| `and` | Và (AND) | `(5 > 3) and (2 < 4)` | `True` |
| `or` | Hoặc (OR) | `(5 > 3) or (2 > 4)` | `True` |
| `not` | Phủ định (NOT) | `not (5 > 3)` | `False` |

## 5. Toán tử định danh

| Toán tử | Ý nghĩa | Ví dụ | Kết quả |
| --- | --- | --- | --- |
| `is` | Trả về True nếu cả hai là cùng một đối tượng | `x is y` | True / False |
| `is not` | Trả về True nếu cả hai không cùng một đối tượng | `x is not y` | True / False |

## 6. Toán tử thành viên

| Toán tử | Ý nghĩa | Ví dụ | Kết quả |
| --- | --- | --- | --- |
| `in` | Trả về True nếu giá trị có trong chuỗi/tập hợp | `'a' in 'apple'` | `True` |
| `not in` | Trả về True nếu giá trị không có trong chuỗi/tập hợp | `'z' not in 'apple'` | `True` |

## Ví dụ

```python
a = 10
b = 20

print(a + b)          # 30
print(a < b)          # True
print(a != b)         # True
print(a and b)        # 20 (b là truthy)
print(a in [5, 10, 15])  # True
```
