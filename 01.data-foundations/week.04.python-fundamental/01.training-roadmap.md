
# Lộ trình học Python

## 1. Kiến thức cơ bản

**Nội dung:**
- Cài đặt Python
- Cú pháp & Chú thích
- Biến & Kiểu dữ liệu
- Toán tử
- Nhập / Xuất dữ liệu

**Mục tiêu:** Xây nền tảng vững chắc.

## 2. Cấu trúc điều khiển

**Nội dung:**
- `if – else`
- Vòng lặp `for`
- Vòng lặp `while`
- `break`, `continue`, `pass`

**Mục tiêu:** Học cách ra quyết định.

## 3. Cấu trúc dữ liệu

**Nội dung:**
- List
- Tuple
- Set
- Dictionary

**Mục tiêu:** Tổ chức và lưu trữ dữ liệu hiệu quả.

## 4. Hàm

**Nội dung:**
- Định nghĩa hàm
- Tham số & Đối số
- Câu lệnh `return`
- Phạm vi (Local & Global)

**Mục tiêu:** Viết code tái sử dụng được.

## 5. Module & Package

**Nội dung:**
- Import module
- Module có sẵn
- Tự tạo module riêng
- `pip` & package bên ngoài

**Mục tiêu:** Tận dụng sức mạnh của Python.

## 6. OOP (Lập trình hướng đối tượng)

**Nội dung:**
- Lớp & Đối tượng
- Kế thừa
- Đa hình
- Đóng gói

**Mục tiêu:** Tư duy theo tình huống thực tế.

## 7. Xử lý tệp tin

**Nội dung:**
- Đọc / Ghi tệp
- Chế độ mở tệp
- `with open()`

**Mục tiêu:** Làm việc với tệp tin.

## 8. Chủ đề nâng cao

**Nội dung:**
- Xử lý ngoại lệ
- List comprehension
- Hàm lambda
- Biểu thức chính quy

**Mục tiêu:** Nâng cao kỹ năng của bạn.

## 9. Dự án

**Nội dung:**
- Làm các dự án nhỏ
- Thu thập dữ liệu web
- Tự động hóa
- API

**Mục tiêu:** Xây dựng, luyện tập và tiến bộ.
