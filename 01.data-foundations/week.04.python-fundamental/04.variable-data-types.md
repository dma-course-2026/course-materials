# Biến và Kiểu dữ liệu

## 1. Biến trong Python

- Biến là vùng chứa dùng để lưu trữ giá trị dữ liệu.
- Trong Python, bạn không cần khai báo kiểu của biến.
- Bạn có thể gán giá trị cho biến bằng toán tử `=`.

Ví dụ:

```python
name = "Minh"       # chuỗi
age = 20            # số nguyên
price = 99.99       # số thực
is_student = True   # luận lý
```

## 2. Quy tắc đặt tên biến

- Phải bắt đầu bằng chữ cái (a–z, A–Z) hoặc `_`.
- Có thể chứa chữ cái, chữ số và `_`.
- Không được bắt đầu bằng chữ số.
- Không được dùng ký tự đặc biệt (`!`, `@`, `#`, ...).
- Không được trùng từ khóa của Python.

Ví dụ:

| Hợp lệ | Không hợp lệ |
| --- | --- |
| `name` | `2age` |
| `_age` | `user-name` |
| `user_name` | `@name` |
| `age2` | `for` |
| `Name1` | `my name` |

## 3. Gán nhiều biến cùng lúc

- Bạn có thể gán giá trị cho nhiều biến trên cùng một dòng.

Ví dụ:

```python
a, b, c = 10, 20, 30  # nhiều giá trị
x = y = z = 5         # cùng một giá trị
```

## 4. Các kiểu dữ liệu trong Python

Python có sẵn các kiểu dữ liệu sau.

| Kiểu dữ liệu | Mô tả | Ví dụ |
| --- | --- | --- |
| `int` | Số nguyên | `x = 10` |
| `float` | Số thập phân | `y = 3.14` |
| `str` | Chuỗi ký tự | `name = "Minh"` |
| `bool` | Giá trị luận lý (True hoặc False) | `is_valid = True` |
| `list` | Tập hợp có thứ tự, thay đổi được | `marks = [85, 90, 95]` |
| `tuple` | Tập hợp có thứ tự, không thay đổi được | `point = (10, 20)` |
| `set` | Tập hợp không thứ tự, phần tử duy nhất | `data = {1, 2, 3}` |
| `dict` | Tập hợp cặp khóa - giá trị | `info = {"name": "Minh", "age": 20}` |

## 5. Kiểm tra kiểu dữ liệu

- Dùng hàm `type()` để kiểm tra kiểu dữ liệu của một biến.

Ví dụ:

```python
x = 10
y = 3.14
name = "Minh"
is_student = False

print(type(x))           # <class 'int'>
print(type(y))           # <class 'float'>
print(type(name))        # <class 'str'>
print(type(is_student))  # <class 'bool'>
```
