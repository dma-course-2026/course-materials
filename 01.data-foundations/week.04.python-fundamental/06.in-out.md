# Nhập và Xuất dữ liệu

## 1. Nhập dữ liệu trong Python

- Ta dùng hàm `input()` để nhận dữ liệu từ người dùng.
- `input()` luôn trả về một chuỗi.
- Cần ép kiểu sang kiểu dữ liệu khác nếu cần.

Cú pháp:

```python
biến = input("thông báo")
```

Ví dụ:

```python
name = input("Nhập tên của bạn: ")
print("Xin chào,", name)

# Nếu người dùng nhập Minh
# Kết quả: Xin chào, Minh
```

### Ép kiểu với input()

| Ép sang kiểu | Cú pháp | Ví dụ |
| --- | --- | --- |
| `int` | `int(input())` | `age = int(input("Tuổi: "))` |
| `float` | `float(input())` | `price = float(input("Giá: "))` |
| `bool` | `bool(input())` | `is_student = bool(input("Bạn là học sinh? (True/False): "))` |

### Lưu ý

- `input()` nhận dữ liệu vào dưới dạng chuỗi.
- Dùng `int()`, `float()`, `bool()`... để chuyển sang kiểu khác.
- Nhấn **Enter** sau khi nhập xong.

## 2. Xuất dữ liệu trong Python

- Ta dùng hàm `print()` để hiển thị kết quả.
- Có thể in ra chữ, số, biến hoặc nhiều giá trị cùng lúc.

Cú pháp:

```python
print(value1, value2, ..., sep=' ', end='\n')
```

Ví dụ:

```python
print("Hello, Python!")          # xuất đơn giản
name = "Minh"
print("Tên tôi là", name)        # kèm biến
print(10, 20, 30)                # nhiều giá trị
print("A", "B", "C", sep='-')    # đổi dấu ngăn cách
print("Xong", end="***")         # đổi phần kết thúc
```

## 3. Ví dụ Nhập và Xuất dữ liệu

```python
name = input("Nhập tên của bạn: ")
age = int(input("Nhập tuổi của bạn: "))
print("Xin chào,", name + "!")
print("Sang năm bạn sẽ", age + 1, "tuổi.")
```

Nếu người dùng nhập:

```text
Nhập tên của bạn: Minh
Nhập tuổi của bạn: 20
```

Kết quả:

```text
Xin chào, Minh!
Sang năm bạn sẽ 21 tuổi.
```

## Mẹo nhanh

- Dùng `input()` để lấy dữ liệu từ người dùng.
- Luôn chú ý đến kiểu dữ liệu.
- Dùng `print()` để hiển thị kết quả.
- Dùng `sep` và `end` để tùy chỉnh đầu ra.
