# Cú pháp và Chú thích

## 1. Cú pháp Python

- Cú pháp Python là tập hợp các quy tắc xác định một chương trình Python hợp lệ.
- Python phân biệt chữ hoa và chữ thường.
- Các câu lệnh được viết theo thứ tự logic.
- Thụt lề được dùng để xác định các khối lệnh.

Ví dụ:

```python
if x > 0:
    print("Số dương")
else:
    print("Không dương")
```

Thụt lề rất quan trọng trong Python.

### Quy tắc cần nhớ

- Thụt lề là bắt buộc.
- Câu lệnh phức bắt đầu bằng dấu hai chấm (`:`).
- Khối lệnh được xác định bằng thụt lề (thường là 4 dấu cách).
- Xuống dòng báo hiệu kết thúc một câu lệnh.

## 2. Chú thích trong Python

Chú thích được dùng để giải thích code.

Python hỗ trợ hai loại chú thích.

### 1. Chú thích một dòng

- Bắt đầu bằng `#`.
- Dùng để chú thích một dòng.

Ví dụ:

```python
x = 10  # Đây là một chú thích
print(x)  # In ra giá trị của x
```

### 2. Chú thích nhiều dòng

- Đặt trong ba dấu nháy (`'''` hoặc `"""`).
- Dùng để chú thích nhiều dòng.

Ví dụ:

```python
"""
Đây là một chú thích
nhiều dòng.
Nó có thể trải dài
qua nhiều dòng.
"""

print("Hello, Python!")
```

## Lưu ý

- Chú thích bị trình thông dịch bỏ qua.
- Chú thích tốt giúp code của bạn dễ hiểu và dễ bảo trì.
