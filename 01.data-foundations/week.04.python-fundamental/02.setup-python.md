# Cài đặt Python


## 1. Cài đặt Python

1. Truy cập [python.org](https://www.python.org/).
2. Tải phiên bản Python mới nhất dành cho hệ điều hành của bạn.
3. Chạy file cài đặt.
4. **Quan trọng:** trên trình cài đặt Windows có tùy chọn này, tích chọn **Add Python to PATH** trước khi cài đặt.

## 2. Kiểm tra cài đặt

Mở **Command Prompt** hoặc **Terminal**, rồi chạy:

```bash
python --version
```

Hoặc:

```bash
python -V
```

Bạn sẽ thấy phiên bản Python đã cài đặt. Ví dụ trong ảnh:

```text
Python 3.12.3
```


## 3. Chọn trình soạn thảo code

Ảnh hướng dẫn khuyến dùng **Visual Studio Code (VS Code)** cho người mới bắt đầu.

1. Truy cập [code.visualstudio.com](https://code.visualstudio.com/).
2. Tải và cài đặt VS Code.
3. Mở VS Code để bắt đầu viết code.

## 4. Chạy chương trình Python đầu tiên

### Tạo file

Tạo file mới có tên `hello.py` và nhập đoạn code sau:

```python
print("Hello, Python!")
```

Lưu file.

### Chạy chương trình

Mở Terminal tại thư mục chứa `hello.py`, rồi chạy:

```bash
python hello.py
```

Kết quả:

```text
Hello, Python!
```

## Mẹo nhỏ

- Cập nhật Python khi phù hợp với yêu cầu và thư viện của dự án.
- Dùng môi trường ảo (*virtual environment*) cho mỗi dự án.
- Luyện tập, xây dựng và tận hưởng quá trình học.
